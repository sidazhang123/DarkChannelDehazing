# DarkChannelDehazing

基于暗通道先验（Dark Channel Prior）的图像去雾 MATLAB 实现，并使用引导滤波（Guided Filter）对透射率图进行细化，从单幅含雾图像中恢复清晰的无雾图像。

## 功能特性

- 采用暗通道先验估计场景透射率与大气光值
- 使用盒式滤波（Box Filter，O(1) 复杂度）与引导滤波对透射率图进行细化，避免边缘伪影
- 完整实现「读取图像 → 暗通道估计 → 大气光估计 → 透射率计算 → 引导滤波细化 → 无雾图像恢复」全流程
- 纯 MATLAB 脚本，无额外第三方依赖，可直接运行

## 技术栈 / 依赖

- 语言：MATLAB
- 依赖工具箱：Image Processing Toolbox（使用 `imread`、`imshow`、`rgb2gray`、`ordfilt2` 等函数）

## 目录结构

```
DarkChannelDehazing/
├── main.m            # 主入口脚本：暗通道先验去雾完整流程
├── boxfilter.m       # O(1) 盒式滤波（基于累计和实现）
└── guidedfilter.m    # O(1) 引导滤波实现
```

## 安装与环境要求

- 已安装 MATLAB（需包含 Image Processing Toolbox）
- 将本项目目录添加至 MATLAB 路径，或将当前工作目录切换至项目目录

## 使用方法

1. 将待去雾的图像命名为 `train.bmp`，放在与 `main.m` 相同的目录下（输入文件名在 `main.m` 中硬编码为 `train.bmp`）。
2. 在 MATLAB 中运行：

```matlab
main
```

脚本会依次弹出两个图像窗口：第一个为原始含雾图像，第二个为去雾后的结果图像。

## 配置说明

`main.m` 中的关键参数均从代码中提取，含义如下：

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| `img_name` | `main.m` 第 5 行 | `'train.bmp'` | 输入图像文件名 |
| `w0` | `main.m` 第 9 行 | `0.85` | 去雾系数，控制保留的雾气程度 |
| 暗通道窗口 | `main.m` 第 21 行 | `15×15` | 暗通道最小滤波窗口大小（`ordfilt2(win_dark,5,ones(15,15))`） |
| `r` | `main.m` 第 35 行 | `80` | 引导滤波的局部窗口半径 |
| `eps` | `main.m` 第 36 行 | `10^-3` | 引导滤波的正则化参数 |
| `t0` | `main.m` 第 38 行 | `0.1` | 透射率下限，避免除零 |

## 输出 / 结果说明

脚本运行后在 MATLAB 图像窗口中显示两幅图：

- 图 1：输入的原始含雾图像 `train.bmp`
- 图 2：去雾后的无雾图像 `dehaze`

去雾图像依据大气散射模型 `I(x) = J(x)·t(x) + A·(1 - t(x))` 反解得到：

```
dehaze = (I - A) / t1 + A
```

其中 `I` 为原始图像，`A` 为估计的大气光值，`t1` 为细化后的透射率图（下限截断为 `t0`）。

## 注意事项 / 已知限制

- 输入图像文件名硬编码为 `train.bmp`，且需为 RGB 彩色图像；如需处理其他图像，请修改 `main.m` 第 5 行的 `img_name`。
- 暗通道估计使用 `ordfilt2(win_dark, 5, ones(15, 15))` 取 15×15 窗口内的第 5 个顺序统计量（代码注释描述为最小滤波，实际参数为 5 而非 1）。
- 透射率细化使用灰度图 `gray_I` 作为引导图，仅在亮度通道上进行。
- 算法面向单幅图像，运行前请确保图像尺寸不至于过大（暗通道估计与恢复过程使用多层 for 循环，大图运行较慢）。
